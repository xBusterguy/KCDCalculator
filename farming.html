Farming Efficiency

Compare every crop by value and by time. Change your trade level and strip conditions and the ranking updates.

Quick setup:

CropGrowsLoads / stripWorth / loadValue / harvestValue / hourEfficiencyvs bestHarvests in windowWindow value
How are these numbers worked out?

Loads per strip = base loads × 1.84 if weeded and watered × (1 + 5% for every trade level above 1). Value per harvest = loads × worth per load × strips. Value per hour = value per harvest ÷ hours to grow. Window value = value per harvest × the number of whole harvests that fit in your time window.

Values are in groschen. Edit “Worth / load” to use your own selling price. Harvests in window counts whole harvests only, so a crop that takes longer than the window shows none.
